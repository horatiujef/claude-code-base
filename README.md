# claude-code-base

Base setup for Claude Code projects.

## Recommended Aliases

Add these to your shell profile (`~/.zshrc` or `~/.bashrc`):

```sh
alias cc='claude --model sonnet --effort medium'                                 # Quick access to Claude Code
alias ccr='caffeinate claude --model sonnet --effort medium "/remote-control"'   # Long session remote control from mobile app
alias cco='claude --model opus --effort high'                                    # Architect mode
```
